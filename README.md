# LAN-Transfer

**A Windows file transfer tool for devices on a local network.**

LAN-Transfer is a Windows application designed to transfer files between devices using IP addresses over a local network.

## Features

- File transfer between devices on a local network.
- IP-address-based connectivity.
- A Windows desktop application.

## Download

Download the latest available release from the official GitHub Releases page:

**[Download LAN-Transfer](https://github.com/Devmoheeb/LAN-Transfer/releases/latest)**

Download the Windows executable (`.exe`) from the release assets.

## Getting Started

1. Open the Releases page linked above.
2. Download the latest published Windows executable.
3. Run the application and follow its on-screen instructions.

## Requirements

- A Windows computer.
- A network connection suitable for communication between the devices.
